# integrated-audit-tools

# 회계법인 정기채용 제출용 프로젝트 통합 저장소

본 저장소는 회계법인 정기채용 제출용으로 개발된 두 개의 애플리케이션 소스코드 및 상세 사용 가이드(PDF)를 통합하여 보관하는 곳입니다. 실무 보안 규정에 따라 민감정보(토큰, 경로 등)는 모두 제거된 상태입니다. 민감정보가 제거됨에 따라 어플 실행이 원활하지 않을 수 있습니다. 상세 사용 가이드에 시연 화면을 첨부해두었으니 확인 부탁드립니다.

---

## 📌 애플리케이션 가이드 바로가기 (PDF)
프로젝트 핵심 요약 및 가이드는 아래 링크에서 즉시 확인하실 수 있습니다.

* 📄 **[감사 데이터 정제 툴 사용 가이드 확인하기](./감사데이터정제툴_설명서.pdf)**
  * 오프라인(폐쇄망) 환경에서 회사마다 제각각인 분개장 데이터를 5단계 파이프라인을 통해 표준 컬럼으로 자동 매핑 및 정제하는 도구입니다.
* 📄 **[일정관리 & 감사업무관리 앱 사용 가이드 확인하기](./일정관리앱_감사업무관리기능_설명서.pdf)**
  * 무한 계층 트리(AuditNode)/칸반 구조의 업무 관리, 활성화된 Excel 조서 창 제목 자동 인식 파이프라인, KICPA 채용공고 자동 수집 기능이 포함된 데스크톱 앱입니다. 이 기능 중 감사업무관리기능의 사용 편리성에 중점을 두어 개발하였습니다.
