# 프로젝트 지침

이 프로젝트(`C:\audit-data-tool`)에서 코드를 수정할 때는 아래 규칙을 반드시 따를 것.

## README.md 동기화 (필수)

- 이 디렉토리의 `README.md`는 앱의 기능·구조·IPC 채널·실행 방법을 설명하는 최신 문서여야 한다.
- 다음에 해당하는 변경을 하면, 같은 작업 안에서 `README.md`의 관련 부분을 실제 코드에 맞게 업데이트할 것:
  - 탭/기능 추가·삭제·변경 (`renderer/index.html`, `renderer.js`)
  - IPC 채널 추가·변경 (`main.js`, `preload.js`)
  - Python 스크립트 추가 또는 정제 로직(입출력 컬럼, 매핑 규칙 등) 변경 (`python/*.py`)
  - 버전(`package.json`) 변경
  - 빌드/실행 방법 변경
- 사용자에게 별도로 묻지 말고, 코드 변경과 함께 README.md 업데이트를 자동으로 수행한다.
- 사소한 리팩터링(변수명 정리, 내부 구현만 바뀌고 동작·구조 설명이 그대로인 경우)까지 매번 문서화할 필요는 없다 — 문서에 적힌 "설명"이 실제와 달라질 때만 갱신한다.
